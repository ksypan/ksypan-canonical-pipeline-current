Выписка из медицинской карты стационарного больного. Медицинская карта № 701523
Пациент: Фридрих Алексеевич Энгельсов; д.р. 28.11.1820; 202 года. Период лечения: с 16.06.2023 по 24.06.2023.

Из анамнеза. Со слов больного, повод для обращения: повторные боли за грудиной в покое и одышка. Несколько суток переносил дискомфорт дома, за медицинской помощью обратился после учащения приступов.
До нынешнего эпизода физическая нагрузка была ограничена преимущественно одышкой; за последние дни переносимость привычной активности снизилась. Ранее обследовался по поводу сердечно-сосудистого заболевания.
Анамнез жизни: Работал в промышленности и публицистике, часто совершал деловые поездки. Повышение АД отмечает несколько лет. Бросил курить. Лекарственная аллергия со слов пациента не отмечалась. Сведения о наследственных сердечно-сосудистых заболеваниях не представлены.

ЧДД 20 в минуту, SpO2 95%. Тоны сердца ритмичные, пульс 101 в минуту, АД 120/83 мм рт. ст. Живот мягкий, безболезненный. Диурез сохранён. Положение активное, контакт доступен. Пульсация периферических артерий сохранена.

Клинический диагноз. Основной диагноз: Острый коронарный синдром без подъёма ST, инфаркт миокарда. Код МКБ-10 I21.4.

При поступлении класс Killip I.

Печёночные ферменты при контрольном исследовании без выраженной динамики.
Дополнительная биохимия: АЛТ 32 Ед/л, АСТ 22 Ед/л, общий белок 70 г/л. Значимых ограничений для продолжения назначенной терапии не выявлено.

Терапия в стационаре. В стационаре проводилось наблюдение с контролем ЭКГ и гемодинамики. После оценки коронарного русла медикаментозная тактика была продолжена с учётом ангиографической картины. Дозы препаратов уточнялись с учётом АД и частоты сердечных сокращений. Назначения корректировались по состоянию в стационаре; при переходе на амбулаторное лечение сформирован отдельный список препаратов.
